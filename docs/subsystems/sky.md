# Sky, background and full-screen effects (slice S5b)

The background of every flight view: sky dome, stars, sun/moon with lens flare and glare, clouds, cloud shadow plane, weather particles, and the full-screen post effects (glow, blur, feedback, flash). Entry: `func_00111B28(cam, list)` from the flight draw (`rendering.md`, "Flight frame"). Everything here is presentation: no simulation state is written, but **`rand()` is called by the sky draw** (`func_00110630`, `func_001145E8`), which advances the C-runtime sequence (`../game/random.md`).

"Draw-env qwords k–(k+1)" below means the 64-bit entries k and k+1 of the main context's draw-env packet (`aDrawenv_pkt`, context +0xC0), written as one A+D pair (data, register) to restore a register. Common names: S = flight scene *0x004104C4; R = mission render settings *0x004104D4 (block 24, `../formats/MISSION.md`); K = sky record *0x004104D0 (0x40 bytes, `mission-load.md` sub 8 `func_00111950`); T = terrain object *0x00410694 (`rendering.md`); W = scratchpad work area 0x70000000 (the sky builds its rings there each view); C = the view's camera object (0x1A0+ bytes, `camera-hud.md`). `LerpColor(t, a, b)` = 0x00104FC8. VU0 helpers by address: 0x001096A8 `SetUnitMatrixVu0`, 0x002632D0/0x00263378/0x00263420 `sceVu0RotMatrixZ/X/Y`, 0x00262F10 `sceVu0ApplyMatrix`, 0x002631C8 `sceVu0CopyMatrix`, 0x00263188 `sceVu0TransMatrix`, 0x00263050 `sceVu0InversMatrix`, 0x00108F00 `MulMatrixVu0`.

## Top level

`func_00111B28(cam, list)`:
1. `func_001119A8(K, cam)` (per-view sky parameters).
2. R+4 bit 0x10 → `func_00116D38(T+0xAC, T+0xB0, cam, list)` (moon); R+4 bit 1 → `func_00117940(T+0x88, T+0x8C, cam, list)` (sun, flare, glare).
3. `func_001115C0(cam, list)` (sky dome).
4. R+4 bit 8 → `func_00118400(R+0x84, cam, list, u16 R+0x82)` (weather particles).
5. R+0xC0 bit 1 → `func_00116918` (stars); bit 2 → `func_00115B10` (sky objects / clouds); bit 4 → `func_00115F28` (cloud shadow plane).
6. K+0 = 0; R+4 bit 0x800 → `func_001120E8((1 − K+0x14) · K+0x1C, list, 0xC, cam, s16 K+0x18 (`lh`), 0xC0C0C0)` (glow).

`func_001119A8(K, cam)`: K+0x30 = C+0x178, K+0x34 = C+0x17C; K+0x38 = (float)(s16 C+0x18C / 2) and K+0x3C = (float)(s16 C+0x18E / 2) (signed halving, rounding toward zero); K+8 = max((int)(C+0x98 / R+0xC + C+0x88), 8) (`cvt.w.s`); K+0xC = K+0x10 = 0; when T+4 == 0 (first map entry) and R+0xC0 bit 8: f = (float)(u32)S+0x1660 · *0x0040DC34, K+0x20 = −R+0xD0 · f, K+0x28 = −R+0xD4 · f (cloud wind offset); else K+0x20 = K+0x28 = 0; K+0x14 = clamp((−C+4 − R+0x10) / (R+0x14 − R+0x10), 0, 1) (altitude factor).

## Sky dome

`func_001115C0(cam, list)`:
1. `func_001102B0(W, W+0x4A0, cam)`; p = −cam+4 (altitude).
2. `func_00110508(p, W+0x7A0, R+0x10)` (gradient colour sets for the altitude), `func_00110630(W+0x498, p, W+0x43C, W+0x7A0, R+0x80)` (ring colours), `func_00110AA8(W+0x498, W, W+0x4A0, R+0x80)` (ring vertices).
3. K+4 = word W+0x454 & 0xFFFFFF; packet: `func_00111138(cur + 16, W, W+0x4A0, K+8)`, then a GIF A+D tag (NLOOP 2, EOP) restoring FRAME/ZBUF from the draw-env packet (main context draw-env qwords 4–5 and 10–11), closed and linked into bucket 1.
4. R+4 bit 4 → second packet: `func_00111310(cur + 16, W, W+0x4A0, cam)` + A+D tag (NLOOP 3) restoring draw-env qwords 4–5, 10–11, 2–3; linked into bucket 5.

`func_001102B0(W, _, cam)` (dome frame; a1 unused):
- 32 ring directions: for i < 32 the pair (a, b) at 0x002A1948 + 8i (`.data`) becomes W+0xD0+16i = (a · 65536, −65536, b · 65536, 1.0) (VU0: `pextlw` gives (a, 0, b, 0), then `vsubx.y`, `vmulx.xz` with vf3.x = 65536.0, `vaddw.w`).
- M = W+0x40 = unit; W+0x2D0 = qword C+0x10 (camera angles); yaw W+0x2D4 = W+0x2D4 − T+0x8C, then −= *0x0040DBE8 when > *0x0040DBE4, else += *0x0040DBF0 when < *0x0040DBEC; M = R(W+0x2D0) (`func_00102D28`); W+0x80 = copy of M (`sceVu0CopyMatrix`).
- v = M · (0, 0, −1, 0) → W+0x2D0; W+0x498 = (W+0x2D8 + 1) · 0.5 (how far the view looks up).
- h = C+4; s = sqrt.s(−h · *0x0040DBF4) (EE `sqrt.s` of the absolute value when negative, `fpu::Sqrt`); f = 65536 / s, capped at 1.0; when s > 65536: W+0x2D0 = (0, 0, 0, 1), W+0x2D4 = h · f, M = `sceVu0TransMatrix(M, (0, h·f, 0, 1))`. W+0x460 = f, W+0x464 = s, W+0x468 = h, W+0x46C = W+0x2D4.
- M = inverse(M) · C+0x60 (`MulMatrixVu0(M, M, C+0x60)`); W+0x80 = `MulMatrixVu0`(inverse(W+0x80), C+0x60); W+0xC0 = qword K+0x30.

`func_00111138(pkt, W, buf, z)` (dome rings → packet; z = K+8): writes a GIF A+D tag (NLOOP 2) with ZBUF_1 = 0x310000A8 and TEST_1 = 0x30000 (Z test ALWAYS), then for rings i = 0 … 28: the dome matrix W+0x40 is loaded into vf4–vf7 with its rows scaled by (u, v, u) of row A[i] (`vmulx`/`vmuly`/`vmulz`, the z scale is u again), vf3 = W+0xC0; ring buffer = buf + (i & 1) · 0x108 (two alternating 33 × 8-byte buffers); mask = rings 0 and 28 → `func_00110FE0(W+0xD0, buffer)` (pole), others → `func_00110F38(W+0xD0, buffer)`. The z word is (z − 8) << 32 for rings 0–14 and z << 32 from ring 15 on (kept for the later rings). When prev_mask & mask ≠ 0: a REGLIST tag (NLOOP 1, NREG 1, register PRIM) with PRIM = 0xC (Gouraud triangle strip), then `func_00111050(ptr, prev_mask & mask, prev_buffer, buffer, &B[i − 1], prev_z, z_word)`. Then prev_* = current. Returns the write pointer.

`func_00111310(pkt, W, buf, cam)` (horizon fog bands, R+4 bit 4): span = min(R+0xC − R+8, 4096); d0 = R+0xC − 4096; step = span · 0.125. A+D tag (NLOOP 4): ZBUF_1 = 0x1_310000A8 (Z write masked), TEST_1 = 0x70000 (Z test GREATER), ALPHA_1 = 0x44, FRAME_1 = 0xFF000000_00080000 (FBP 0, FBW 8, alpha writes masked). For rings i = 14 … 20: matrix scaled by A[i] and ring projected as above (`func_00110F38` only); when prev_mask & mask ≠ 0, 8 bands j: d = d0 + j · step (accumulated with `add.s`), z = (int)(C+0x98 / d + C+0x88) << 32 (for both rings), an A+D tag (NLOOP 1, PRE with PRIM 0x4C: Gouraud alpha-blended strip) setting ALPHA_1 = (f << 32) | 0x64 with f = 16 + 8j (fixed alpha), then `func_00111050(ptr, prev_mask & mask, prev_buffer, buffer, &B[i − 1], z, z)`. Returns the write pointer.

`func_00110508(p, out, g)` (gradient by altitude; g = R+0x10: g[0], g[1] altitude keys, 48 bytes of colours at g+0x10 and at g+0x40): p ≤ g[0] → out = the 48 bytes at g+0x10; p ≥ g[1] → the 48 bytes at g+0x40; else u = (p − g[0]) / (g[1] − g[0]) and three 16-byte MMI lerps `func_001050D8(out + 16k, g+0x10+16k, g+0x40+16k, u)` for k = 0, 1, 2 (`../game/math.md`).

`func_00110630(t, p, out, g, s)` (ring colours; t = W+0x498 in f12, p = altitude in f13, out = W+0x43C (9 colour words), g = W+0x7A0 (the gradient set), s = R+0x80):
- out[0] = g+0x20, out[1] = g+0x24; g+0x30 = 16-byte lerp `func_001050D8(g+0x30, g, g+0x10, t)`; out[2..5] = the 4 words at g+0x30; out[6] = LerpColor(t, g+0x28, g+0x2C); out[7] = LerpColor(t, s+8, s+0xC); out[8] = s+0x10.
- a = T+0xA8 · *0x0040DBF8, b = T+0xA4 · *0x0040DBF8; for out[8] then out[7] (two passes): p > b → out[k] = out[6]; else p > a → out[k] = LerpColor((p − a) · (1 / (b − a)), out[k], out[6]); then a, b = a · 0.5, b · 0.5.
- Colour adjust of out[0..4] (VU0, per byte lane x = R, y = G, z = B, w = A: `vitof0`, add, clamp to 0…255 with `vmaxx` vf0 / `vminibcx` 255.0, optional multiply and clamp again, `vftoi0` truncation, `ppach`/`ppacb` repack): p ≥ *0x0040DBFC → add (0x70, 0x70, 0x42, 0) · −1, then multiply by 1 − (p − *0x0040DBFC) · *0x0040DC00; else p ≥ *0x0040DC04 → add (0x70, 0x70, 0x42, 0) · ((p − *0x0040DC04) · *0x0040DC08), no multiply.
- Glow g' = K+0xC: when g' − 0.5 > 0, g' = 1 − cosf((g' − 0.5) · *0x0040DC0C), else 0. When main-context flag 0x100 is clear and K+0 bit 0 is set: **one `rand()`**, u = (r >> 8) & 0xFFF; u > 0x800 → g' += (1 − K+0x14) · ((float)u · *0x0040DC10). When g' > *0x0040DC14: out[0..4] += (0x60, 0x60, 0x60, 0) · g' (clamped, times 1.0, clamped).
- Finally the alpha byte of out[0..8] = 0x80.

`func_00110AA8(t, W, _, s)` (ring heights and colours; t in f12 = W+0x498, s = R+0x80; a1 unused). Ring rows: A = W+0x2E0 (29 pairs (u, v) of floats), B = W+0x3C8 (29 colours); c0…c8 = W+0x43C…W+0x45C (from `func_00110630`); E = the 32-entry `.data` table at 0x002A1948 (pairs (a, b)); q = T+0xA4 · 2⁻¹⁶.
- H = W+0x2D0…W+0x2DC = `sceVu0InterVector`(s+0x30, s+0x20, t) (0x00263100: s+0x30 · t + s+0x20 · (1 − t)).
- rows 0–7: A = (E[k].a, E[k].b · 0.5 + s+0x18), B = LerpColor(E[k].b, c1, c0).
- rows 8–9 (f = 0, 0.5): A = (1.0, s+0x18 + (H0 − s+0x18) · f), B = LerpColor(f, c1, c2); rows 10–11: (1.0, H0 + (H1 − H0) · f), LerpColor(f, c2, c3); rows 12–14 (f = 0, 0.5, 1.0): (1.0, H1 + (H2 − H1) · f), LerpColor(f, c3, c4).
- rows 15–19 (f = 0, 0.25 … 1.0): e = ((W+0x468 · *0x0040DC18) − W+0x46C · 2⁻¹⁶) / q; A = (1 − (f · q) · 0.5, s+0x1C + (e − s+0x1C) · f), B = LerpColor(f, c5, c6).
- row 20: B = c6, A = (q · 0.5, e' = ((W+0x468 · q) · *0x0040DC1C − W+0x46C · 2⁻¹⁶) / q − *0x0040DC20).
- rows 21–28 (n = k − 20, E[n] = (a, b)): A = ((b · 0.5) · q, e' − a · 0.25); B = a ≤ H3 ? LerpColor(a / H3, c6, c7) : LerpColor((a − H3) / (1 − H3), c7, c8).

`func_00110F38(pts, out)` → 33-bit mask: for i < 32, r = `func_0010FFB8(out + 8i, pts + 16i)`, then word out+8i+4 = r (replacing the z word), bit i set when r ≥ 0; the 8 bytes at out+256 = those at out (ring closed); returns mask | (bit 0 << 32).

`func_00110FE0(p, out)` (a point replicated, for the dome cap): r = `func_0010FFB8(out, p)`; r < 0 → returns 0; else word out+4 = r, the 8 bytes at out are copied to out+8 … out+256, returns 0x1FFFFFFFF.

`func_00111050(pkt, mask, A, B, cols, za, zb)` (strip between two projected rings; 64-bit `mask`, `za`/`zb` 64-bit values OR'ed into the XYZ register words, `cols` = 2 colour words): for i < 32 while mask ≠ 0: when bits i and i + 1 are both set and the clip words (+4) of A[i], A[i+1], B[i], B[i+1] share no bit: 8 registers at the write pointer (starting pkt + 16): RGBAQ cols[0], XYZ3 za | A[i], RGBAQ cols[0], XYZ3 za | A[i+1], RGBAQ cols[1], XYZ2 zb | B[i], RGBAQ cols[1], XYZ2 zb | B[i+1] (each 64 bits; the A pair only queues vertices, the B pair kicks two strip triangles), n += 1; mask >>= 1. When n > 0 the GIF tag at pkt = NLOOP n, EOP, FLG 1 (REGLIST), NREG 8, regs 0x5151D1D1, and the end of the data is returned; otherwise pkt is returned unchanged.

`func_001100A0(angles, yaw, pitch)` (fog/sky colour toward a direction; yaw in f12, pitch in f13): t = `func_00110170(yaw, angles)`; p = −pitch; p ≤ R+0x10 → (a, b) = (R+0x48, R+0x4C); p ≥ R+0x14 → (R+0x78, R+0x7C); else u = (p − R+0x10) / (R+0x14 − R+0x10), a = LerpColor(u, R+0x48, R+0x78), b = LerpColor(u, R+0x4C, R+0x7C); returns LerpColor(t, a, b).

`func_00110170(yaw, angles)` → f0: M = unit, RotZ(angles.z), RotX(angles.x); d = angles.y − yaw, then −= *0x0040DBD8 when > *0x0040DBD4, else += *0x0040DBE0 when < *0x0040DBDC; M = RotY(d) · M; returns (M · (0, 0, −0.5, 0)).z + 0.5.

`func_00110240(out, pitch, yaw)` (f12, f13): M = unit, RotX(pitch), RotY(yaw); out = third row of M (`vmulw` by vf0.w).

`func_0010FFB8(out, p)` (VU0 projection; the caller loads the matrix into vf4–vf7 and the screen rectangle into vf3 = (cx, cy, half-w, half-h)):
- v = M · p (`vmulax/vmadday/vmaddaz/vmaddw`). The MAC-flag read (`cfc2` vc1, three `vnop`s later) is one of the reads PCSX2 reorders with a GameDB patch (`../port/validation.md` B-2): it sees the flags of the **`vmaddaz`**, so the test is on ACC.w = M[0].w · p.x + M[1].w · p.y + M[2].w · p.z (without the fourth row): zero or negative (bits 0x11) → return −1 (nothing stored).
- Q = 1 / v.w; v.xyz = v.xyz · Q; i = `vftoi4`(v) (12.4 fixed); out (8 bytes) = u16 i.x, u16 i.y, u32 (i.z >> 4) (logical shift of the zero-extended value) — an XYZ2-style screen position.
- The status register is cleared, then v.xy − 0 and (4096, 4096) − v.xy set the sticky zero/sign flags: when either is set (x or y ≤ 0 or ≥ 4096) → return −1 (out already written).
- d.xy = v.xy − vf3.xy; `vclipw.xyz d, (d.w = vf3.z)` then `vclipw.xyz d, vf3` (against vf3.w); returns clip & 0xCC (bits 6–7: |d.x| > half-w from the first test; bits 2–3: |d.y| > half-h from the second); 0 = inside.

## Full-screen post effects

The glow/blur effects work on GS buffers through sprite copies: the frame is reduced in up to 3 levels (half size each) and blended back. All register words not listed are constants in the code (`.data` tables 0x002A1A48…0x002A1AE8 and gp words 0x004104D8/0x004104E0 hold the TEX0/FRAME values per level).

`func_00111C80(p, n, scissor, tex, frames)` (downsample level n; returns p unchanged for n < 0): w = 0x2000 >> n, c = (0x1C0 << (4 − n)) + 0x40, cnt = (w / 512 rounded toward zero) · (2 when n = 0). A+D (PRE, PRIM 0x316 = textured FST sprite, context 2) SCISSOR_2 = scissor. For each pass k < 2ⁿ: REGLIST TEX0_2 = tex[k]; for j = 0, 1: A+D FRAME_2 = frames[2k + j] (the pointer advances continuously); REGLIST NREG 4 (UV, XYZ2, UV, XYZ2) NLOOP cnt; for each column x = 0, 0x200 … < w: UV (x + 16j, 16j), XYZ2 (x/2, 0), UV (x + 16j + 0x1F8, c + 16j), XYZ2 (x/2 + 0xFC, c/2); when n = 0 also UV (x + 16j, 0x1BF8), XYZ2 (x/2, 0xE00 − 16j), UV (x + 16j + 0x1F8, 0x1BF8), XYZ2 (x/2 + 0xFC, 0xE80). Returns the write pointer.

`func_00111EC8(p, n, scissor, tex, frames, colA, colB)` (upsample/blend level n): w = 0x2000 >> n, c = (0x1C0 << (4 − n)) + 0x20. A+D (PRE, PRIM 0x356 = textured FST alpha-blended sprite, context 2) SCISSOR_2 = scissor. For each pass k < 2ⁿ: A+D FRAME_2 = frames[k]; for j = 0, 1: REGLIST (RGBAQ, TEX0_2) = (j == 0 ? colA : colB, tex[2k + j]); REGLIST NREG 4 NLOOP (w / 512 rounded toward zero) with o = 12 − 8j: for x = 0, 0x200 … < w: UV (x/2 + o, o), XYZ2 (x, 0), UV (x/2 + o + 0xFC, c/2 + o), XYZ2 (x + 0x1F8, c). Returns the write pointer.

`func_001120E8(t, list, bucket, cam, levels, colour)` (glow; t in f12): nothing when t ≤ 0 or levels ≤ 0; t capped at 1. Packet: `BuildMenuDrawEnv(cur + 16, draw_w, draw_h)`; A+D (NLOOP 2) XYOFFSET_2 = 0, TEXFLUSH; REGLIST (CLAMP_2, RGBAQ) = (5, 0x80808080); `func_00111C80` for level 0 (scissor 0x00FF000000FF0000, tex 0x004104D8, frames 0x002A1AB8), level 1 (0x007F0000007F0000, 0x002A1A48, 0x002A1AC8) when levels > 1, level 2 (0x003F0000003F0000, 0x002A1A58, 0x002A1AE8) when levels > 2; A+D ALPHA_2 = 0x44; `func_00111EC8` level 2 (0x007F0000007F0000, 0x002A1A78, 0x002A1AC8, 0x80808080, 0x40808080) when levels > 2, level 1 (0x00FF000000FF0000, 0x002A1A58, 0x002A1AB8, same colours) when levels > 1; final level 0 blend `func_00111EC8(…, 0, scissor = cam+0x1A0, 0x002A1A48, &draw-env qword 2, (q << 24) | c, (L << 24) | c)` with c = LerpColor(t, 0x808080, colour & 0xFFFFFF), L = (int)(t · 64), q = (L << 7) / (128 − L) (unsigned 64-bit `__udivdi3`); A+D TEXFLUSH (EOP); `CloseDmaPacket`, `LinkPacket(list, bucket)`.

`func_00112450(list, bucket, cam, levels)` (blur): nothing when levels < 1. Same draw env, (CLAMP_2, RGBAQ), downsample chain (levels 0–2), ALPHA_2 = 0x44 and upsample levels 2 and 1 as in `func_001120E8`; then `func_00111EC8(…, 0, 0x01BF000001FF0000, 0x002A1A48, 0x004104E0, 0x80808080, 0x40808080)`; then A+D (NLOOP 3, PRE PRIM 0x356): FRAME_2 = draw-env qword 2 | 0xFF00000000000000 (alpha writes masked), SCISSOR_2 = cam+0x1A0, ALPHA_2 = 0x54 ((Cs − Cd) · Ad + Cd: blend by destination alpha); REGLIST (TEX0_2, RGBAQ) = (0x264123100, 0x80808080); REGLIST NREG 4 (UV, XYZ2, UV, XYZ2) NLOOP 8 EOP: for x = 0, 0x400 … 0x1C00: UV (x + 8, 9), XYZ2 (x, 0), UV (x + 0x400, 0x1C09), XYZ2 (x + 0x3F8, 0x1C00); `CloseDmaPacket`, `LinkPacket(list, bucket)`.

`func_001132E0(list, bucket, a)` (fill the frame's **alpha channel** with a, clamped to 0…255, for the destination-alpha blends): A+D (NLOOP 5, PRE PRIM 6 = flat sprite): FRAME_1 = 0x00FFFFFF00080000 (FBMSK 0x00FFFFFF: only alpha is written), ZBUF_1 = 0x1310000A8 (Z masked), TEST_1 = 0x30000, XYOFFSET_1 = 0, RGBAQ = a << 24; `BuildSpriteStrips(ptr, 0, 0x1C002000)` (full-screen strips); A+D (NLOOP 4, EOP) restoring draw-env qwords 2–3, 4–5, 10–11, 6–7; `CloseDmaPacket`, `LinkPacket(list, bucket)`.

`func_00113468(p, frame, scissor, xyoffset)` (context 2 setup; A+D NLOOP 9, EOP): FRAME_2 = frame, SCISSOR_2 = scissor, XYOFFSET_2 = xyoffset, ZBUF_2 = 0x131000000 (Z masked), TEST_2 = 0x30000, TEX1_2 = 0x60, TEXA = 0x80, CLAMP_2 = 0, COLCLAMP = 1; returns p + 0xA0.

`func_00112CA8(list, bucket, cbp, cam)` (frame alpha remap through a table): A+D (NLOOP 4) BITBLTBUF = 0x1B01000000000000 | (cbp << 32), TRXPOS = 0, TRXREG = 0x1000000010 (16 × 16), TRXDIR = 0; an IMAGE tag (NLOOP 16) with 256 bytes: entry i = (i < 128 ? 128 − i : i) & 0xFF, stored at index (i & 0xE7) | ((i & 0x10) >> 1) | ((i & 8) << 1) (bits 3 and 4 swapped, the CLUT layout); A+D TEXFLUSH (EOP); A+D (NLOOP 5, PRE PRIM 0x116 = textured FST sprite): FRAME_1 = ((draw_w >> 6) << 16) | 0x00FFFFFF00000000 (only alpha written), ZBUF_1 = 0x1310000A8, TEST_1 = 0x30000, XYOFFSET_1 = 0, TEX1_1 = 0; REGLIST (TEX0_1, RGBAQ) = ((draw_w >> 6) << 14 | 0x2000000000000000 | (cbp << 37) | 0xEA9B00000, 0x80808080) (the frame read as a PSMT8H texture through the table); `BuildSpriteStripsUv(ptr, (x0, y0), (x1, y1), (x0 + 8, y0 + 9), (x1 + 8, y1 + 9))` with x0 = s16 C+0x188 · 16, x1 = (C+0x188 + C+0x18C) · 16, y0 = s16 C+0x18A · 16, y1 = (C+0x18A + C+0x18E) · 16; A+D (NLOOP 4, EOP) restoring draw-env qwords 2–3, 4–5, 10–11, 6–7; `CloseDmaPacket`, `LinkPacket(list, bucket)`.

`func_00113988(p, fbp, w, h)` (clear a work page as render target): n = (w + 63) / 64 (signed); n ≤ 0 → returns p. A+D (NLOOP 6, PRE PRIM 6): FRAME_1 = (fbp >> 5) | ((w / 64) << 16), ZBUF_1 = 0x1310000A8, TEST_1 = 0x30000, XYOFFSET_1 = (0x8000 − 8w) | ((0x8000 − 8h) << 32), SCISSOR_1 = ((w − 1) << 16) | ((h − 1) << 48), TEX1_1 = 0x60; REGLIST (CLAMP_1, RGBAQ) = (0, 0); REGLIST NREG 2 (XYZ2, XYZ2) NLOOP n, EOP: x = 0x8000 − 8w, step 0x400: XYZ2 (x, 0x8000 − 8h), XYZ2 (x + 0x400, 0x8000 + 8h) (black, alpha 0).
